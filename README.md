# Behruz uchun shaxsiy sayt

O'zbek tilidagi zamonaviy, moslashuvchan (mobil qurilmalarga mos) shaxsiy sayt.

## Imkoniyatlar
- Bosh sahifa, "Men haqimda", "Ko'nikmalar", "Loyihalar", "Aloqa" bo'limlari
- Yorug' / qorong'i mavzu
- Yozuv effekti va scroll animatsiyalari
- Mobil menyu
- Aloqa formasi (tekshiruv bilan)

## Ishga tushirish
`index.html` faylini brauzerda oching — boshqa hech narsa kerak emas.

## O'zgartirish
- Matnlar va loyihalar: `index.html`
- Ranglar: `style.css` faylidagi `:root` o'zgaruvchilari
- Ijtimoiy tarmoq havolalari: `index.html` dagi `.socials` bo'limi
